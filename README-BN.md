# মৌলভী মোঃ মিছির আলী স্মৃতি ফুটবল টুর্নামেন্ট ২০২৬ — ওয়েবসাইট

## এই প্যাকেজে আছে
- Responsive বাংলা ওয়েবসাইট
- আপনার দেওয়া ৩টি লোগো `assets/` ফোল্ডারে
- ৩২টি দলের প্রাথমিক কাঠামো (৮ গ্রুপ × ৪ দল)
- প্রতি গ্রুপের ৬টি করে প্রাথমিক ম্যাচ (মোট ৪৮টি গ্রুপ ম্যাচ)
- গ্রুপ পয়েন্ট টেবিল, ফিক্সচার, নকআউট ব্র্যাকেট
- অ্যাডমিন প্যানেল: দলের নাম/গ্রুপ, ম্যাচের তারিখ-সময়-ভেন্যু ও স্কোর
- ম্যাচ পোস্টার PNG ডাউনলোড
- Supabase যুক্ত করার প্রস্তুত ব্যবস্থা

## আগে জেনে নিন
এখনকার ডিফল্ট `LOCAL DEMO MODE`-এ অ্যাডমিন পাসওয়ার্ড `admin123`। এই মোডে পরিবর্তন শুধু একই ব্রাউজারের local storage-এ থাকে। এটি অনলাইনে সবার জন্য ডেটা সিঙ্ক করে না এবং বাস্তব অ্যাডমিন নিরাপত্তার বিকল্প নয়।
সবার জন্য একই ডেটা ও নিরাপদ অ্যাডমিন লগইন পেতে Supabase সেটআপ করতে হবে।

## অনলাইনে সম্পূর্ণ ফ্রি প্রকাশের ধাপ
1. https://supabase.com এ ফ্রি অ্যাকাউন্ট খুলে New project তৈরি করুন।
2. Supabase-এর SQL Editor-এ `supabase-setup.sql` ফাইলের সব SQL চালান।
3. Authentication > Users থেকে আপনার নিজের অ্যাডমিন ইমেইল ও শক্তিশালী পাসওয়ার্ড দিয়ে user তৈরি করুন। Public sign-up বন্ধ রাখুন।
4. Project Settings > API থেকে Project URL ও anon/public key কপি করুন।
5. `config.js` ফাইলে `supabaseUrl` ও `supabaseAnonKey`-তে মান দুটি বসান।
6. এই ফোল্ডারের সব ফাইল GitHub repository-তে আপলোড করুন।
7. https://pages.cloudflare.com এ গিয়ে GitHub repository connect করে deploy করুন। Framework preset: None; Build command ফাঁকা; Output directory `/` বা root দিন।
8. Deploy শেষে Cloudflare Pages-এর `*.pages.dev` ঠিকানায় ওয়েবসাইট খুলুন।

## প্রথমবার চালানো
- ওয়েবসাইট খুলে অ্যাডমিন অংশে Supabase-এর তৈরি করা ইমেইল/পাসওয়ার্ড দিয়ে লগইন করুন।
- দলের নাম ও গ্রুপ ঠিক করে সংরক্ষণ করুন।
- ম্যাচের তারিখ, সময়, ভেন্যু ও স্কোর দিয়ে সংরক্ষণ করুন।
- পোস্টার ট্যাবে দল বেছে নিয়ে তারিখ-সময়-ভেন্যু দিয়ে PNG ডাউনলোড করুন।

## গুরুত্বপূর্ণ সীমাবদ্ধতা ও পরবর্তী উন্নয়ন
- এই starter version-এ গ্রুপের পয়েন্ট টেবিল স্বয়ংক্রিয়ভাবে হিসাব হয়।
- নকআউট ব্র্যাকেটের জায়গাগুলো দেখানো আছে; গ্রুপের শীর্ষ দুই দল অনুযায়ী নকআউট ম্যাচ স্বয়ংক্রিয়ভাবে বসানোর কাজ এখনো যুক্ত করা হয়নি।
- দলীয় লোগো আপলোডের বদলে বর্তমানে লোগোর image URL রাখা যায়; Supabase Storage যুক্ত করে সরাসরি আপলোড পরবর্তী ধাপে করা যাবে।
- পোস্টার ডাউনলোড কাজ করে; এই প্রথম সংস্করণে পোস্টারে দলীয় লোগো এমবেড করা হয়নি।
- Supabase SQL নীতিতে authenticated users-দের write অনুমতি আছে। তাই Supabase Authentication-এ শুধু আপনার অ্যাডমিন user রাখবেন, public sign-up বন্ধ রাখবেন।
- Supabase free tier-এর ব্যবহারসীমা ও inactivity policy পরিবর্তিত হতে পারে; সম্পূর্ণ ফ্রি থাকার নিশ্চয়তা কোনো তৃতীয়-পক্ষ সেবার ক্ষেত্রে দেওয়া যায় না।
